# MamaCare

MamaCare is an offline-first Expo application for local vitamin reminders and intake tracking.

## Run locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go on an Android phone connected to the same network. Local notifications require a physical device; allow notification access when prompted.

## Checks

```bash
npm run typecheck
npm run lint
npx expo-doctor
```
